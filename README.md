

Requisitos funcionais:

RF1 - Cadastrar Produto: Cadastra um novo produto com nome, categoria, descrição, preço, quantidade e data de validade

RF2 - Listar Produtos: Exibe todos os produtos cadastrados na tela principal

RF3 - Editar Produto: Permite alterar as informações de um produto existente

RF4 - Excluir Produto: Permite remover um produto do estoque

Requisitos nao funcionais:

RNF1 - Segurança (Prepared Statements): Utiliza Prepared Statements para prevenir ataques de SQL Injection

RNF2 - Validação de Dados: Impede o envio de formulários com campos obrigatórios em branco.
